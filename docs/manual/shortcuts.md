# Keyboard shortcuts

Every keyboard shortcut in the desktop app, the Markdown you can type in a message, and the slash commands. Press `?` or `Ctrl+/` in the app to see the same list.

## How keys are written here

`Ctrl` means the Control key. On macOS, `Cmd` works wherever `Ctrl` is shown; Concord treats the two the same. `Alt` is the Option key on a Mac.

Most shortcuts keep working while you are typing a message. The exceptions are `?`, which types a question mark when a text field has focus (use `Ctrl+/` instead), and `↑` for editing, which only applies in an empty message box.

On a phone, only the typed items (Markdown and slash commands) apply, and the shortcut list shows only those.

## Navigation

| Keys | Action |
|---|---|
| `Ctrl+K` | Command palette |
| `Ctrl+F` | Search messages |
| `Ctrl+,` | Settings |
| `Ctrl+Shift+,` | Network stats and diagnostics |
| `Alt+↑` / `Alt+↓` | Previous / next channel |
| `Alt+Shift+↑` / `Alt+Shift+↓` | Previous / next unread channel |
| `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | Previous / next guild |
| `Ctrl+U` | Show or hide the member panel |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Zoom in / zoom out / reset zoom |
| `?` or `Ctrl+/` | Show the shortcut list |

The command palette jumps to any guild, channel or direct message by typing part of its name; with nothing typed, it lists the channels you visited most recently. It also runs app actions such as **New message**, **Create guild**, **Join with an invite code**, **Can people reach me?**, **Set status** and **Mark all as read**. Start the query with `>` or `/` to see actions only. It does not open while a dialog is up.

`Ctrl+F` goes to the search box when a channel is open; otherwise the browser's own find bar opens as usual. Zoom ranges from 80% to 150% in steps of 10%.

## Reading

| Keys | Action |
|---|---|
| `Esc` | Close whatever is on top (a menu, panel, dialog or open forum post). With nothing open, mark the current channel read. |
| `Shift+Esc` | Mark everything read |

With the cursor in an empty message box, `Esc` moves focus out of the box.

## Voice

| Keys | Action |
|---|---|
| `Ctrl+Shift+M` | Mute or unmute your microphone |
| `Ctrl+Shift+D` | Deafen or undeafen |
| Your push-to-talk key | Hold to talk, when push-to-talk is on |

Mute and deafen only do something while you are in a call.

## Composer

| Keys | Action |
|---|---|
| `Enter` | Send |
| `Shift+Enter` | New line |
| `↑` | Edit your last message |
| `Ctrl+Shift+L` | Switch text direction |

## Formatting

These wrap the selected text in the matching Markdown. With nothing selected, they insert the markers at the cursor. The same formats are on the composer's formatting toolbar.

| Keys | Format |
|---|---|
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+E` | Inline code |
| `Ctrl+Shift+U` | Underline |
| `Ctrl+Shift+S` | Strikethrough |
| `Ctrl+Shift+K` | Link |
| `Ctrl+Shift+X` | Spoiler |
| `Ctrl+Shift+.` | Quote |

## Markdown

| Type | Result |
|---|---|
| `**text**` | Bold |
| `*text*` | Italic |
| `__text__` | Underline |
| `~~text~~` | Strikethrough |
| `\|\|text\|\|` | Spoiler |
| `` `code` `` | Inline code |
| ```` ```block``` ```` | Code block |
| `> ` | Quote this line |
| `>>> ` | Quote the rest of the message |
| `# `, `## `, `### ` | Headers |
| `[text](url)` | Masked link |

## Slash commands

Type `/` at the start of a message to get a menu of these.

| Command | What it does |
|---|---|
| `/shrug [message]` | Appends ¯\\\_(ツ)\_/¯ |
| `/tableflip [message]` | Appends (╯°□°)╯︵ ┻━┻ |
| `/unflip [message]` | Appends ┬─┬ ノ( ゜-゜ノ) |
| `/fa [message]` | ┻━┻ ︵╰(°□°╰) fa me (╯°□°)╯︵ ┻━┻ |
| `/me <action>` | An action, in your name |
| `/spoiler <text>` | Hides the text until clicked |
| `/timestamp [message]` | Seals the exact send time onto this message |
| `/confetti [message]` | Sends with a confetti burst |
| `/fireworks [message]` | Sends with fireworks |
| `/hearts [message]` | Sends with floating hearts |
| `/meme` | Opens the meme editor |
| `/gif` | This guild's GIF pack |
| `/doodle` | Draw something |
| `/sound` | Send a sound, or build one |
| `/game` | Start a game in this channel |
| `/clear <n>` | Delete the last *n* messages. Listed only for people who can moderate the channel. |

## Changing keys

The push-to-talk key is the one binding you choose yourself. Set it in **Settings → Voice & video**: under **Mic activation**, select **Push to talk**, then the button next to **Hold**, and press the key. Any key works, including a modifier on its own such as Right Ctrl, except `Esc` and `Tab`. Bindings follow the physical key, so they work the same on any keyboard layout.

Push-to-talk only works while the Concord window has focus. Concord does not register system-wide hotkeys. If the key also types a character, it will not open your microphone while you are typing a message; combine it with `Ctrl` or `Alt`, or use a function key, to have it work everywhere in the window.

The other shortcuts cannot be changed.
